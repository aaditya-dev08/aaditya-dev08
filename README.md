I'm an **MCA (AI/ML) candidate** and **AI/ML Engineering Intern at CoRover.ai (BharathGPT)**, with hands-on
experience designing and developing LLM-powered, agentic, and retrieval-augmented systems. I build
multi-agent orchestration platforms, semantic retrieval pipelines, and optimization systems using
**Python, FastAPI, LangChain/LangGraph, and PyTorch**. My work sits at the intersection of
**rigorous ML research** and **enterprise-grade software engineering** — from designing LangGraph-based agent
workflows with conditional execution and checkpointing, to architecting scalable FastAPI/PostgreSQL backends

observable, and trustworthy. My paper, **E-RLHF**, is currently in review at *SN Computer Science (Springer)*.

containerized deployments, and real-time systems (WebSockets, streaming pipelines) that ship end-to-end,
not just in notebooks.

## 🔬 Research

### E-RLHF: Explainability-Guided Reinforcement Learning from Human Feedback
**In Review — SN Computer Science (Springer)**

- Designed a novel framework integrating **Explainable AI (XAI)** with **RLHF**, combining SHAP-based feature
  attribution with policy learning.
- Built a custom dataset with causal and spurious features to systematically analyze model behavior and robustness.
- Implemented neural network models in **PyTorch** and proposed an explanation-guided penalty mechanism to improve
  interpretability without sacrificing performance.
- Improved explanation fidelity from **0.61 → 0.84** while maintaining **98% predictive accuracy**, validated through
  comparative experiments and feature-removal studies.

`PyTorch` `SHAP` `RLHF` `Explainable AI`
